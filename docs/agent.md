# Dictionary agent (`/agent`)

A chat assistant that answers Sanskrit questions from this site's data: dictionaries, inflection
tables (śabdarūpa / dhāturūpa / kṛdanta), the dhātupāṭha and the Aṣṭādhyāyī with commentaries,
plus web search.

- Backend: `src/agent/` (Rust, [aisdk](https://aisdk.rs) tool loop) + `src/routes/agent.rs`.
- Models (OpenRouter, default reasoning, no reasoning parameter sent):
  `gpt-6-luna` → `openai/gpt-6-luna` (default), `claude-sonnet-5.5` → `anthropic/claude-sonnet-5.5`.
- Model calls use OpenRouter's **Responses API** (`/api/v1/responses`).
- Web search: the `web_search` function tool, through OpenAI's Responses API with its native
  `web_search` tool (model `gpt-6-luna`). It returns a factual summary with source URLs; the same
  for both chat models. Needs `OPENAI_API_KEY`.
- Storage: `agent_chats`, `agent_messages` (AI SDK `UIMessage` parts as JSON).
- Env: `OPENROUTER_API_KEY`, `OPENAI_API_KEY` (only for web search; without it the agent answers
  from the dictionaries and omits the tool).

## HTTP

| Method | Path | Body / query | Response |
|---|---|---|---|
| POST | `/api/agent/chat` | `{ id, message, model, dicts }` | UI message stream (SSE, AI SDK v5+ protocol) |
| GET | `/api/agent/chat/{id}/stream` | – | the reply being generated, replayed from its start then live (`useChat({ resume: true })`); 204 when none runs on this instance |
| GET | `/api/agent/context` | `dicts`=comma slugs (the reader's preferred dictionaries) | `AgentContext` |
| GET | `/api/agent/chats` | – | `AgentChatSummary[]` (newest first, max 300) |
| GET | `/api/agent/chats/{id}` | – | `{ chat: AgentChat, messages: AgentUIMessage[] }` (404 if unknown) |
| PATCH | `/api/agent/chats/{id}` | `{ title }` | `AgentChatSummary` |
| DELETE | `/api/agent/chats/{id}` | – | 204 |
| POST | `/api/agent/chats/{id}/stop` | – | 204 (aborts the reply being generated, on any instance) |

`POST /api/agent/chat`:
- `id`: chat id generated by the client (`useChat` id); the chat row is created on the first message.
- `message`: only the new user `UIMessage` (`{ id, role: 'user', parts: [{ type: 'text', text }] }`);
  history is loaded from the database. Resending a stored message id (regenerate) replays the
  history up to that message and replaces what followed.
- `model`: `'gpt-6-luna' | 'claude-sonnet-5.5'`.
- `dicts`: the reader's preferred dictionary slugs (home-page search preference). The agent
  searches these by default; it may search any other dictionary when useful or when asked.
- A message sent while a reply is still generating stops that reply first.
- The new user message is stored when the turn starts; the reply keeps generating and is saved
  even if the client disconnects. A client opening a chat whose `streaming` is true reconnects
  to `/api/agent/chat/{id}/stream` (same instance only — on another instance it gets 204 and
  polls the chat until the saved reply lands).

```ts
type AgentModelId = 'gpt-6-luna' | 'claude-sonnet-5.5';

interface AgentChatSummary {
  id: string; title: string; model: AgentModelId; streaming: boolean;
  created_at: string; updated_at: string;   // ISO
}
interface AgentChat extends AgentChatSummary { dicts: string[]; }

interface AgentMessageMetadata {
  model?: AgentModelId;
  cost?: number;                  // USD actually charged by OpenRouter (web searches are billed to OpenAI separately)
  usage?: { inputTokens?: number; outputTokens?: number; cachedInputTokens?: number;
            reasoningTokens?: number };
  webSearches?: number;           // finished web_search tool calls in this reply
}

type AgentUIMessage = UIMessage<AgentMessageMetadata, never, AgentUITools>;

/** Exactly what the model is given (for the Context dialog). */
interface AgentContext {
  system_prompt: string;                    // full text, Markdown
  tools: { name: string; description: string; parameters: unknown }[];  // JSON Schema
  server_tools: { type: string; parameters: unknown }[];  // none currently
  max_tool_calls: number;                   // per turn
  models: { id: AgentModelId; provider_id: string }[];
}
```

Assistant message parts, in order: `step-start`, `reasoning` (text; `providerMetadata.openrouter.
reasoning_items` kept for replay — the UI ignores it; a reasoning part with empty `text` only
carries encrypted reasoning and must not be rendered), `text`, `tool-<name>` (states
`input-streaming` → `input-available` → `output-available` | `output-error`).

## Tools (`AgentUITools`)

All Sanskrit input may be in any script (Devanagari, IAST, HK, ITRANS, SLP1); output headwords
are Devanagari. `text` fields are plain text (HTML stripped) and may be truncated (`…`).
Links in the UI: entry → `/entry/$id`, paradigm → `/paradigm/$id`, dhātu → `/dhatu/$id`,
sūtra → `/sutra/$id`, dictionary → `/dict/$slug`.

```ts
type AgentUITools = {
  web_search: {                            // through OpenAI's web_search, same for both models
    input: { query: string };
    output: { summary: string; sources: { url: string; title?: string }[] };
  };
  search_dictionaries: {
    input: { query: string; dicts?: string[]; mode?: 'sa' | 'en'; limit?: number };
    output: {
      query: string; mode: 'sa' | 'en'; slp1: string[];
      searched: string[] | 'all';            // dictionary slugs searched
      results: { dict: string; dict_name: string; total: number;
                 entries: { id: number; headword: string; match: string; text: string }[] }[];
      forms: { form: string; lemma: string; root: string | null; analysis: string;
               source: string; paradigm_ids: number[] }[];   // inflected-form analysis
      did_you_mean: string[];
    };
  };
  get_entry: {
    input: { id: number };
    output: { id: number; headword: string; dict: string; dict_name: string; text: string;
              truncated: boolean; sutra_id: string | null; dhatu_id: number | null };
  };
  suggest_headwords: {
    input: { prefix: string; limit?: number };
    output: { items: { headword: string; count: number }[] };
  };
  browse_dictionary: {
    input: { dict: string; headword: string; before?: number; after?: number };
    output: { dict: string; dict_name: string; center: number;
              items: { id: number; seq: number; headword: string }[] };
  };
  find_paradigms: {                          // declension / conjugation / kṛdanta tables
    input: { query: string };                // stem (prātipadika) or root
    output: { query: string; total: number;
              paradigms: { id: number; source: string; lemma: string; root: string | null;
                           label: string | null }[] };
  };
  get_paradigm: {
    input: { id: number; group?: string; title?: string };   // filter conjugation tables
    output: { id: number; source: string; lemma: string; root: string | null;
              label: string | null; tables: ParadigmTable[];  // same shape as /api/paradigms/{id}
              groups: { group: string | null; titles: (string | null)[] }[];  // all available
              filtered: boolean };
  };
  search_dhatus: {
    input: { query?: string; gana?: number };
    output: { total: number; dhatus: Dhatu[] };            // max 40
  };
  get_dhatu: {
    input: { id: number };
    output: { dhatu: Dhatu;
              works: { dict: string; dict_name: string;
                       entries: { id: number; headword: string; text: string }[] }[] };
  };
  search_sutras: {
    input: { query: string };                // number prefix (1.1, 3.2.123) or text
    output: { total: number; sutras: { id: string; text: string }[] };   // max 40
  };
  get_sutra: {
    input: { id: string; commentaries?: string[] };          // commentary slugs
    output: { sutra: { id: string; text: string }; prev: string | null; next: string | null;
              commentaries: { dict: string; dict_name: string; text: string;
                              truncated: boolean }[] };
  };
  // Grammar tools on vidyut (src/agent/vidyut_tools.rs → src/vidyut). Roots / stems / words in
  // any script; ids as in docs/api.md § Vidyut. `page` = the matching /vidyut/* tool page.
  vidyut_conjugate: {
    input: { root: string; gana?: number; prayoga?: PrayogaId; lakara?: LakaraId;
             sanadi?: SanadiId[]; upasargas?: string[] };       // root: any script or code 08.0010
    output: { root: VidyutRoot; homonyms: VidyutRoot[]; stems: string[]; prayoga: PrayogaId;
              columns: 'eka | dvi | bahu';
              tables: { pada: PadaId; lakara: LakaraId; rows: string[] }[];  // "प्रथमपुरुषः: a | b | c"
              page: string };
  };
  vidyut_decline: {
    input: { stem: string; linga: LingaId };
    output: { stem: string; linga: LingaId; columns: string; rows: string[]; page: string };
  };
  vidyut_krdantas: {
    input: { root: string; gana?: number; sanadi?: SanadiId[]; upasargas?: string[] };
    output: { root: VidyutRoot; homonyms: VidyutRoot[];
              groups: { group: string; items: string[] }[];   // "क्त — past passive participle: कृत"
              page: string };
  };
  vidyut_derivation: {
    input: { root?: string; gana?: number; sanadi?: SanadiId[]; upasargas?: string[];
             prayoga?: PrayogaId; lakara?: LakaraId; purusha?: PurushaId;   // verb form
             stem?: string; linga?: LingaId; vibhakti?: VibhaktiId;          // noun form
             vacana?: VacanaId; form?: string };                            // form: pick a variant
    output: { results: string[]; form: string;
              optional_rules: { rule: string; applied: boolean }[];
              steps: { rule: string; sutra_id: string | null; text: string | null;
                       result: string }[];                                  // max 80
              truncated: boolean };
  };
  vidyut_sandhi: {
    input: { join?: string[]; split?: string };
    output: { words: string[]; joined: string[]; page: string }
          | { note: string; chunks: { chunk: string; splits: string[] }[]; page: string };
                                                    // splits: "तथा✓ + एव✓" (✓ = in the dictionaries), max 12
  };
  vidyut_meter: {
    input: { verse: string };
    output: { meter: MeterMatch | null;
              lines: { syllables: string; pattern: string; ganas: string; matras: number }[];
              also_compatible: string[]; page: string };
  };
};

interface VidyutRoot { code: string; upadesha: string; root: string; artha: string; gana: number }
```

`ParadigmTable` and `Dhatu` are the API types in `docs/api.md`; the vidyut ids and `MeterMatch`
are in its § Vidyut.
