# शब्दकोशः · Sanskrit Dictionary (frontend)

TanStack Start SPA (static client app) + React 19 + TanStack Query + shadcn
`base-nova` on `@base-ui/react` + Tailwind v4 + Lipi Lekhika. Talks only to the
Rust axum JSON API — see [`../docs/api.md`](../docs/api.md) for the contract.

## Run

```sh
cd frontend
bun install
bun run dev        # vite dev on :3010, /api proxied to axum
```

The API base is always the relative path `/api/...`. In dev, `/api` is proxied
to the axum server at `http://127.0.0.1:5780` via a nitro `routeRules` proxy
(override with `AXUM_DEV_ORIGIN=http://… bun run dev`). In production the
static build
(`bun run build` → `.output/public/` static SPA shell + assets, plus a tiny node
entry in `.output/server/`) is served from the same origin as axum,
so `/api` resolves to the backend with no extra config.

## Lipi Lekhika typing behavior

- `src/components/lipi/typing.tsx` — `LipiTypingProvider` holds `enabled`
  (default **off**, persisted in `localStorage` as `sans-dict-lipi-enabled`) and
  the typing `script` (default `Devanagari`, persisted as
  `sans-dict-lipi-script`), plus a memoized `createTypingContext(script)` that
  preloads via `void ctx.ready` in an effect.
- `useLipiInput(value, setValue)` returns `{ value, onChange, onBeforeInput, onBlur, onKeyDown }`
  wired to `handleTypingBeforeInputEvent(ctx, e, setValue, enabled)` and
  `clearTypingContextOnKeyDown`; **Alt+X / Alt+C** toggles typing (with
  `preventDefault`).
- The search bar and the browse “jump to headword” input carry the compact
  toggle (switch + language icon, title “Lipi Lekhika typing (Alt+X)”); the
  search settings popover has the typing-script select (full `SCRIPT_LIST`).
- Typing never fires unless the user opts in; with it off the inputs are plain
  controlled fields, so any transliteration (IAST/SLP1/…) passes through to the
  server untouched.

## Display script

The header select (`src/components/script/`) transliterates headwords (and
sūtra/dhātu headings) client-side with `transliterate(text, 'Devanagari', to)`
— batched per list, memoized in a module-level cache. `Devanagari` (default)
renders with zero transliteration cost; other scripts fall back to the source
text if transliteration fails.

## Routes

- `/` — search (`q`, `mode`, `dicts`), suggest dropdown, results grouped per dictionary
- `/entry/$id` — single entry + browse-nearby panel
- `/dict/$slug` — book-order browse (`seq`/`q`)
- `/sutra`, `/sutra/$id` — sūtra list + detail with commentary tabs
- `/dhatu`, `/dhatu/$id` — dhātu table (gaṇa filter) + detail with work tabs
- `/about` — dictionary list + credits
